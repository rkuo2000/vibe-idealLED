Connection settings & help

Type 2 is the repository default. Select the protocol matching your firmware; identical device names can use different protocols. Type 1 supports color and power here; effects are available for Type 2.

Use Chrome or Edge with Web Bluetooth on a supported computer or Android device. Serve this folder over HTTPS, or use localhost. Safari and Firefox do not provide the required API. Close other apps connected to the curtain before pairing.

Effects use the repository’s IDs 1–10; their appearance depends on the controller. Commands are encrypted locally. Color channels are limited to 5 bits, following the upstream controller. No account or cloud service is needed.

Protocol source: 8none1/idealLED. Only devices using that repository’s protocol are supported.
